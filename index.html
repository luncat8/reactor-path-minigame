03 / TRAJECTORY GUIDANCE

The guide searches the forecast for the nearest compatible future return state, interpolated between samples. The next selected delay is excluded, then influence fades in smoothly for one second. Position, heading, and speed all take part in selection, so a closer crossing moving the wrong way cannot capture the beam. The force combines a pull toward the return point with movement matching; it may turn, accelerate, or brake gently to arrive in the same state and form a loop. Distance and direction controls fade impossible matches to zero; perpendicular and opposing passes are never used. In debug: green ring and arrow = target state, cyan arrow = current movement, dashed line = position error, white arrow = actual matching force. Set strength or reach to 0 to disable.
